# 🧠 Quiz Challenge Game

A Python CLI-based quiz game with scoring system.

## 🚀 Features
- Multiple choice questions (JSON based)
- Score system (+10 / -10)
- Bonus points for streaks
- Penalty for wrong streaks
- Final dashboard summary
- User selects number of questions

## 🛠️ Tech Used
- Python
- JSON

## ▶️ How to Run
```bash
python main.py
